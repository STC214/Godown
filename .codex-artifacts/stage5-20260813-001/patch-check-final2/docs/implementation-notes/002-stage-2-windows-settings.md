## Implemented

- SQLite-backed settings persistence.
- Settings dialog for download folder, proxy, headers, cookies, retry/concurrency/speed limits, FFmpeg, and M3U8 runtime options.
- Per-user single-instance guard.
- System tray behavior:
  - close and minimize hide to tray.
  - tray menu can show the main window, open downloads, start all, pause all, or exit.
- Tray balloon notifications for task completion and failure.
- Embedded Windows application icon and manifest resources.
- Browser extension settings foundation:
  - enable/disable flag.
  - persistent pair token generated by the desktop app.
  - bridge port, defaulting to `14370`.
  - token display and regeneration in Settings.

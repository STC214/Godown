# Stage 23：复审和 FTP 完成状态收尾

## 本次变更

- `app.Run` 在任务读取失败时返回错误，保留原始记录；不再启动空调度器。
- 调度器增加 `loadFailed` 写入保护，读取失败后即使执行退出清理，也不覆盖任务存储。后续成功读取后恢复正常持久化。
- FTP 在 EOF 后检查最终服务器回复和本地文件关闭错误，确认成功后才将 `.part` 发布为最终文件。
- FTP 数据流关闭使用 `sync.Once`，避免取消与正常退出同时关闭造成竞争；最终回复等待使用连接超时上限。
- 未知大小 FTP 下载完成后回报实际大小和 100%（含空文件）。

## 验证与交付

新增回归先在原实现上失败：任务读取失败仍写入一次；FTP 426 回复被当作成功；未知大小完成时大小与进度仍为 0。修复后执行定向测试、竞态检查、全量测试和 `go vet`。

实际命令、输出和退出码见 `018-stage-23-verification.txt`。
增量差异见 `018-stage-23.patch`，只包含本轮变更，不撤销 Stage 21/22 工作区内容。
便携包：`release/GhostDownloader-0.1.16-stage23-windows-x64-portable.zip`。

回退脚本：`scripts/rollback-stage23.ps1`。依赖本机 `.codex-artifacts/stage23-original` 和 `stage23-modified` 快照；执行前检查所有目标文件是否仍匹配快照，避免覆盖后续修改。仅恢复本轮涉及的源码和 README，不触碰用户数据库，也不删除版本包。二进制回退使用保留的 Stage 22 压缩包。此脚本不是数据库迁移或跨 Windows 用户凭据迁移工具。

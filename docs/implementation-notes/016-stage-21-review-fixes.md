# Stage 21：Stage 20 功能复审修复

日期：2026-09-05

## 修复内容

- FTP 地址解析对畸形 URL 返回错误，不再解引用空解析结果。
- FTP 输出文件名按 Windows 规则替换非法字符、清理尾随点和空格，并规避保留设备名。
- FTP 服务器不支持 `SIZE` 时以未知大小继续传输；其他协议错误仍会终止任务。
- BT 文件选择窗口支持低、普通、高三级实际下载优先级，新任务默认普通优先级。
- `Scheduler.EditTask` 串行处理同一时刻的编辑，并在停止阶段拒绝重新应用或启动任务，避免旧副本覆盖较新的检查点。
- BT 自动测试客户端仅监听回环接口，同时关闭 IPv6、DHT 和自动端口映射；正式程序网络配置不变。

## 测试补强

- 使用真实 BEP 52 v2-only file tree 生成元数据，再由其真实哈希生成 `btmh` Magnet，验证 v2-only 解析与持久化。
- 使用临时 ECDSA 证书启动回环隐式 FTPS 控制通道和加密数据通道，完成解析与下载。
- 使用回环 FTP 夹具验证不支持 `SIZE` 时仍可完成未知大小文件下载。
- 覆盖 BT 三级优先级持久化、引擎映射、进度裁剪、UI 操作和并发任务编辑。

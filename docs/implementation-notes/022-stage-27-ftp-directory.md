# Stage 27：FTP 递归目录下载

## 实现

- `ftp://`、`ftps://`、`ftpes://` 地址接受目录；末尾 `/` 可明确表示目录，无末尾 `/` 时在 SIZE 文件探测失败后尝试目录遍历。
- 创建任务时递归读取远程清单并持久化远程路径、安全本地相对路径、类型和大小，最多 100,000 项。
- 保留空目录，跳过符号链接；逐段清理 Windows 非法字符、设备名和尾随点/空格，并按 Windows 大小写规则拒绝清理后的路径冲突。
- Worker 顺序下载目录文件，复用全局限速、连接超时、重试和 REST 续传；大小相同的已完成文件直接计入进度，`.part` 从已有偏移继续。
- 目录任务报告聚合大小、速度、当前相对路径及最终 100% 状态。
- Redownload/Cleanup 只在下载根目录边界内递归删除该任务的目录，不影响相邻文件。
- 加载持久清单时再次检查本地路径、重名、负数大小和远程根目录，防止损坏数据造成越界写入。

## 验证

本机 FTP 端到端夹具覆盖无尾斜杠目录识别、两级目录、空目录、Windows 文件名清理、已完成文件跳过、嵌套 `.part` 从偏移 12 续传、内容和聚合进度。另有目录清理边界和路径冲突测试。完整命令与输出见 `022-stage-27-verification.txt`。

# Stage 16：设置窗口布局与简体中文界面

日期：2026-09-05

## 目标

- 修复设置窗口内容区宽度只按首选尺寸显示、右侧出现大面积空白的问题。
- 让设置窗口在常见 Windows 工作区高度下保持可操作，保存和取消按钮始终位于固定底栏。
- 将主窗口、设置窗口、任务状态、托盘菜单、通知、更新提示、浏览器配对和种子文件选择界面统一为简体中文。

## 实现

- 设置窗口默认高度由 900 调整为 720，最小高度由 720 调整为 620。
- 滚动内容区设置 700 逻辑像素最小宽度并启用伸展因子，输入框和分组会占用可用横向空间。
- 保留垂直滚动，在低分辨率或高 DPI 环境中仍可访问全部设置。
- 用户可见按钮、标签、筛选项、状态文本、错误提示、通知和托盘操作改为简体中文。
- 内部配置值及协议标识（例如 `dark`、`mp4`、DHT、UPnP）保持不变，避免影响配置兼容性。
